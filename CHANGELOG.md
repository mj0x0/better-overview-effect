# Changelog

## 0.1.0 — 2026-09-12

Initial release.

- Floating panel with one tile per virtual desktop; windows at their real positions, sharp at any size.
- Click a tile or a window to go there. Middle-click closes. Drag a window to another desktop without following it.
- Keys: arrows or `hjkl`, `1`–`9` and `0`, `Esc`/`Enter`; the wheel steps desktops.
- Minimized windows as icon chips at the bottom of their tile.
- Multi-monitor: a panel per screen, other screens in a sidebar, drop a window on one to send it there.
- Optional blur behind the panel, wallpaper in tiles, hide empty rows.
- Settings page. No key bound by default; bind it under System Settings → Shortcuts → Window Management.
